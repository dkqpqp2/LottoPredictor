# 타로 카드 78장 확장 설계

## 배경 및 목적

`/tarot`의 카드 덱은 현재 메이저 아르카나 22장(0~21번)뿐이다. 세 가지 모드(타로만 보기, 별자리 함께보기, 번호 뽑기용 타로) 모두 이 22장 안에서만 카드를 뽑는다. 기능이 어느 정도 자리 잡은 지금, 정식 타로 78장 풀 덱(메이저 아르카나 22장 + 마이너 아르카나 56장)으로 확장한다.

## 범위

**포함:**
- 마이너 아르카나 56장(지팡이/성배/검/오망성 4개 수트 × 14장) 데이터 추가 — 이름(한글/영문), 키워드, 4방향(위/아래/왼쪽/오른쪽) 운세 문구
- 56장 카드 이미지 추가 (기존 22장과 동일 출처)
- 번호 뽑기용 타로 모드의 카드→로또 시드값 매핑을 78장 기준으로 일반화

**제외:**
- 카드 배열/드래그/AI 해석 프롬프트 등 카드 수에 의존하지 않는 로직 — 변경 불필요 (이미 `TAROT_CARDS` 배열 길이에 무관하게 동작)
- 사용자 지정 덱 커스터마이징, 카드 이미지 애니메이션 개선 등 — 이번 스코프 아님

## 아키텍처

### 카드 번호 체계

메이저 아르카나 0~21번은 그대로 유지한다. 마이너 아르카나 56장은 22~77번을 이어서 부여하며, 순서는 지팡이(Wands, 22~35) → 성배(Cups, 36~49) → 검(Swords, 50~63) → 오망성(Pentacles, 64~77) 4개 수트, 각 수트 안에서는 에이스~10 → 시종(Page) → 기사(Knight) → 여왕(Queen) → 왕(King) 순으로 14장씩 배치한다.

### 시드값 매핑 (`tarotNumberGenerator.ts`)

기존:
```ts
export function cardSeedNumber(card: TarotCard): number {
  return card.number === 0 ? 22 : card.number;
}
```

일반화:
```ts
export function cardSeedNumber(card: TarotCard): number {
  return (card.number % 45) + 1;
}
```

**주의: 이 변경은 기존 22장의 시드값을 전부 1씩 밀어낸다.** 기존 로직은 `0 → 22`(바보만 특별 취급), `1~21 → 1~21`(나머지는 카드번호 그대로)이었다. 새 공식으로는 `0 → 1`, `1 → 2`, ..., `21 → 22`가 되어 바보를 포함한 22장 전부의 시드값이 바뀐다. 아래 "설계 결정" 섹션에서 이 트레이드오프를 명시한다.

### 설계 결정: 시드값 하위 호환성을 깨는가?

기존 특별 취급(`0 → 22`)은 "바보 카드의 시드값 0은 무의미하니 22로 옮긴다"는 임시방편이었다. 78장 체계에서는 이런 특별 취급 없이 `(card.number % 45) + 1`로 통일하는 게 자연스럽고, 카드-시드값 관계가 어차피 임의적인 재미 요소이므로 기존 22장의 시드값이 전부 1씩 밀리는 것은 사용자 경험에 실질적 영향이 없다(어느 카드를 뽑아도 45개 로또 번호 중 그럴듯한 하나에 가중치가 실리는 게 목적이지, 특정 카드가 특정 시드값을 가져야 한다는 요구사항은 없었다). 기존 22장의 정확한 가중치 재현이 아니라 "78장 전체에 일관된 규칙 적용"을 우선한다.

### 카드 콘텐츠

56장 전부에 대해 기존 22장과 동일한 스키마(`TarotCard` 인터페이스 변경 없음)로 이름/키워드/4방향 운세 문구를 새로 작성한다. 톤은 기존 카드들과 동일 — 따뜻하고 격려하는 2인칭 문장, 점술적 단정 대신 가벼운 참고용 조언.

### 이미지

기존 22장과 동일하게 Wikimedia Commons의 퍼블릭도메인 라이더-웨이트 덱(1909년 출간, 저작권 만료)에서 마이너 아르카나 56장 이미지를 내려받아 `frontend/public/tarot/22.jpg`부터 `77.jpg`까지 저장한다.

## 영향받는 파일

- `frontend/lib/tarotCards.ts` — `TAROT_CARDS` 배열에 56개 항목 추가
- `frontend/lib/tarotCards.test.ts` — 카드 수(78)와 번호 범위(0~77) 검증으로 갱신
- `frontend/lib/tarotNumberGenerator.ts` — `cardSeedNumber` 일반화
- `frontend/lib/tarotNumberGenerator.test.ts` — 새 시드값 매핑에 맞게 갱신
- `frontend/public/tarot/22.jpg` ~ `77.jpg` — 신규 이미지 56개

## 테스트

- `tarotCards.test.ts`: 78장, 번호 0~77 중복 없음, 전 카드 4방향 운세 존재 확인 (기존 테스트 구조 그대로, 숫자만 갱신)
- `tarotNumberGenerator.test.ts`: `cardSeedNumber`가 메이저/마이너 아르카나 각각에 대해 `(number % 45) + 1`을 반환하는지 확인
- 이미지 파일 존재 여부는 자동 테스트 대상이 아님 (기존 22장도 동일) — 브라우저 수동 확인으로 카드 스프레드에서 이미지가 깨지지 않는지 확인
